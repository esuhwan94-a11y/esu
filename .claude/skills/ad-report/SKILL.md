# 09 성과분석

입력: `brief.md`, `07-채널운영.md`, `08-광고개선.md`, 광고·채널 지표 · 출력: `ads/<광고주>/09-성과분석.md`

## 1. 지표 수집
- 기간(주간 / 월간)과 비교 기간(직전 같은 길이)을 먼저 정한다.
- 광고: 쓴 돈, 노출, 클릭, 전환, 전환당 비용, 광고비 대비 매출. 메타는 연결된 읽기 도구로, 나머지는 사용자가 준 파일로.
- 채널: 팔로워 변화, 게시물별 도달·저장·공유.
- 매출·문의 수는 광고주가 준 숫자만 쓴다.
- 숫자마다 출처와 기간을 적는다. 못 구한 숫자는 "미확인"으로 둔다.

## 2. 패턴 분석
- brief의 목표 대비 어디까지 왔는지 먼저 본다.
- 직전 기간과 비교해 크게 달라진 것 3가지와 그 이유로 보이는 것. 이유가 추정이면 추정이라고 적는다.
- 소재·주제·형식·요일별로 묶어 잘 된 쪽과 안 된 쪽을 본다.
- 표본이 작은 비교는 결론으로 쓰지 않는다.
- 표와 차트가 필요하면 dataviz 스킬을 쓰고, 광고주에게 엑셀로 줄 때는 xlsx 스킬을 쓴다.

## 3. 개선 제안
3개 이내. 각각:
- 할 일 (그만할 것 / 더 할 것 / 새로 해 볼 것)
- 근거가 된 숫자
- 기대하는 변화
- 필요한 것(예산, 자료, 광고주 결정)

제안은 다음 달 `03-콘텐츠기획.md`와 `08-광고개선.md`의 출발점이 된다.

## 출력 틀
```
# 성과분석: <광고주> (기간)
## 세 줄 요약
## 목표 대비
## 숫자 (표, 출처 포함)
## 달라진 것과 이유
## 다음에 할 일
## 확인하지 못한 숫자
```
광고주에게 보낼 때는 세 줄 요약과 다음에 할 일을 맨 앞에 둔다. 나쁜 숫자도 빼지 않는다.
