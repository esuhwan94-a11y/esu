# 01 시장조사

입력: `ads/<광고주>/brief.md` · 출력: `ads/<광고주>/01-시장조사.md`

## 1. 트렌드 수집
- 웹 검색으로 최근 3개월 안의 업종 소식, 계절 요인, 검색어 흐름, 플랫폼에서 뜨는 형식을 찾는다.
- 조사량이 많으면 deep-research 스킬에 맡긴다.
- 각 항목에 출처 주소와 날짜를 붙인다. 날짜를 모르면 "시점 불명"이라고 적는다.

## 2. 경쟁사 비교
brief의 경쟁사 2~3곳(없으면 검색으로 3곳)을 같은 틀로 본다.

| 항목 | 볼 것 |
|---|---|
| 내세우는 약속 | 첫 화면·대표 광고의 한 문장 |
| 가격·혜택 | 가격대, 할인, 무료배송 등 |
| 채널·빈도 | 어디에 얼마나 자주 올리는지 |
| 잘 되는 콘텐츠 | 반응이 큰 게시물의 형식과 주제 |
| 빈틈 | 말하지 않는 것, 불만 댓글 |

직접 볼 수 없는 것(광고비, 실제 매출)은 추측하지 않고 "확인 불가"로 적는다.

## 3. 기회 탐색
경쟁사가 비워 둔 자리와 트렌드가 겹치는 곳을 3개 이내로 고른다. 각각 이렇게 적는다.
- 기회: 한 문장
- 근거: 위 조사 중 어느 것
- 광고에서 쓸 각도: 한 문장
- 불확실한 점

## 출력 틀
```
# 시장조사: <광고주> (조사일)
## 한눈에 (3줄)
## 트렌드
## 경쟁사 비교표
## 기회 (우선순위순)
## 확인하지 못한 것
```
