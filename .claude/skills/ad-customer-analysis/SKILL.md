# 02 고객분석

입력: `brief.md`, `01-시장조사.md` · 출력: `ads/<광고주>/02-고객분석.md`

## 1. 리뷰 수집
- 우선순위: 광고주가 준 리뷰·문의 파일 → 공개 상품 리뷰 → 경쟁사 리뷰 → 커뮤니티·댓글.
- 고객이 쓴 말을 고치지 않고 그대로 옮긴다. 어디서 가져왔는지 적는다.
- 이름, 연락처, 주문번호는 옮기지 않는다.
- 모은 양이 20건 미만이면 그 사실을 맨 위에 적는다. 적은 표본으로 단정하지 않는다.

## 2. 고민 분류
리뷰를 네 갈래로 나눈다.
- 사기 전 고민: 무엇이 불편해서 찾았나
- 망설인 이유: 가격, 의심, 귀찮음
- 산 뒤 좋았던 점: 고객이 쓴 표현 그대로
- 산 뒤 불만

갈래마다 자주 나온 순으로 정리하고 대표 인용 2~3개를 붙인다.

## 3. 타깃 정리
타깃을 1~3개로 묶는다. 타깃마다:
- 누구: 상황으로 적는다(나이·성별만 적지 않는다). 예: "퇴근 후 20분 안에 저녁을 차려야 하는 맞벌이"
- 가장 큰 고민
- 사게 만드는 한 가지
- 망설이게 하는 한 가지와 그에 대한 답
- 자주 보는 채널
- 고객 말투로 쓴 표현 5개 (카피 단계에서 그대로 쓴다)

## 출력 틀
```
# 고객분석: <광고주>
## 자료 (출처별 건수)
## 고민 분류
## 타깃 1 / 2 / 3
## 광고에 쓸 고객 표현 모음
## 자료가 부족한 부분
```
