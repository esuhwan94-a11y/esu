# 07 채널운영

입력: `03-콘텐츠기획.md`, `04-카피대본.md`, `05-디자인/`, `06-영상/` · 출력: `ads/<광고주>/07-채널운영.md`

## 1. 게시물 준비
일정표의 게시물마다 한 묶음을 만든다.
- 채널, 올릴 날짜·시간
- 파일(이미지·영상) 경로
- 본문 글, 해시태그, 광고 표기
- 링크, 댓글 고정 문구

## 2. 발행 검토
올리기 전에 묶음을 사용자에게 보여 주고 확인받는다. 점검표:
- 오탈자, 가격·날짜·링크가 맞는가
- 채널 규격(크기, 길이)에 맞는가
- 광고 표기와 금지 표현
- 광고주 승인이 필요한 건인가

확인받은 건만 올린다. 틱톡은 연결된 계정으로 올릴 수 있다(계정 확인 → 발행 준비 → 상태 확인). 연결이 없는 채널은 올릴 파일과 글을 한 묶음으로 정리해 사용자가 직접 올리게 한다. 계정 비밀번호를 받아 대신 로그인하지 않는다.

## 3. 반응 확인
올린 뒤 1일·3일·7일에 본다. 사용자가 원하면 예약 작업으로 걸어 둔다.

| 게시물 | 도달 | 좋아요 | 댓글 | 저장·공유 | 링크 클릭 | 메모 |
|---|---|---|---|---|---|---|

- 볼 수 없는 지표는 빈칸으로 두고 사용자에게 화면 캡처를 요청한다. 숫자를 짐작해 채우지 않는다.
- 답이 필요한 댓글·문의는 답글 초안을 써 두고, 올리는 것은 사용자가 한다.
- 반응이 좋은 게시물은 08의 광고 소재 후보로 표시한다.
