# 04 카피·대본

입력: `brief.md`, `02-고객분석.md`, `03-콘텐츠기획.md` · 출력: `ads/<광고주>/04-카피대본.md`

03의 주제 하나마다 아래 세 가지를 쓴다. 말투는 brief를 따르고, 표현은 02의 "고객 표현 모음"에서 먼저 가져온다. 긴 페이지 문구는 copywriting 스킬을 함께 쓴다.

## 1. 후킹 문구
- 주제마다 5개. 서로 다른 방식으로 쓴다: 고민 그대로 말하기 / 숫자 / 뜻밖의 사실 / 전후 비교 / 질문.
- 영상은 첫 2초 안에 읽히는 길이, 카드 표지는 두 줄 이내.
- 본문이 지키지 못할 약속으로 낚지 않는다.

## 2. 본문 작성
- 카드뉴스: 장마다 한 가지 말만. 장 번호와 문구를 표로.
- 게시 글: 첫 줄에 핵심, 그다음 근거, 마지막에 행동 유도. 해시태그는 5개 이내로 따로.
- 영상 대본: 초 단위 표.

| 초 | 화면 | 말(자막) |
|---|---|---|
| 0–2 | | 후킹 |
| 2–10 | | 고민 공감 |
| 10–22 | | 해결·증거 |
| 22–30 | | 행동 유도 |

## 3. 행동 유도
- 한 게시물에 할 일은 하나만. "프로필 링크", "DM으로 '가격'", "저장해 두기"처럼 바로 할 수 있는 말로 쓴다.
- 기한·수량 한정은 실제로 그럴 때만 쓴다.

## 내보내기 전 점검
- 근거 없는 최상급·보장 표현이 없는가
- 수치마다 출처가 brief의 근거 자료에 있는가
- brief의 금지 표현이 없는가
- 대가성 게시물에 광고 표기를 넣었는가
- 광고 소재용은 문구를 2~3개 버전으로 남겼는가 (08에서 비교)
