# 03 콘텐츠기획

입력: `brief.md`, `01-시장조사.md`, `02-고객분석.md` · 출력: `ads/<광고주>/03-콘텐츠기획.md`

## 1. 주제 발굴
- 02의 고민마다, 01의 기회마다 주제를 뽑는다. 주제는 "누구의 어떤 고민에 무엇을 보여 준다"로 적는다.
- 기간에 필요한 수의 1.5배를 뽑고, brief 목표에 가까운 순으로 줄인다.
- 목적을 섞는다: 알리기(처음 보는 사람), 믿게 하기(후기·과정), 사게 하기(혜택·마감). 대략 4:4:2로 시작한다.

## 2. 구성 설계
주제마다 한 줄씩 정한다.

| 항목 | 내용 |
|---|---|
| 형식 | 카드뉴스 / 짧은 영상 / 단일 이미지 / 글 |
| 타깃 | 02의 타깃 번호 |
| 첫 장면·첫 문장 방향 | 무엇으로 멈추게 할지 |
| 전개 | 장수 또는 초 단위 흐름 |
| 행동 유도 | 보고 나서 할 일 하나 |
| 필요한 자료 | 사진, 후기, 수치와 출처 |

## 3. 일정 정리
- brief의 주당 횟수에 맞춰 날짜·채널·주제를 표로 만든다.
- 제작에 걸리는 날을 거꾸로 세어 "제작 시작일"도 적는다.
- 사용자가 원하면 구글 캘린더에 일정으로 넣는다. 넣기 전에 넣을 목록을 보여 준다.

## 출력 틀
```
# 콘텐츠기획: <광고주> (기간)
## 방향 한 줄
## 주제 목록 (구성표)
## 일정표
## 광고주에게 받아야 할 자료
```
