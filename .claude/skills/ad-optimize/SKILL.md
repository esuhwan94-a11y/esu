# 08 광고개선

입력: `brief.md`, `04-카피대본.md`, `07-채널운영.md`, 광고 계정 지표 · 출력: `ads/<광고주>/08-광고개선.md`

## 1. 소재 비교
- 메타 광고 계정이 연결돼 있으면 읽기 도구로 소재별 지표를 가져온다. 없으면 사용자에게 내보내기 파일을 받는다.
- 소재마다: 노출, 클릭률, 클릭당 비용, 전환 수, 전환당 비용, 쓴 돈.
- 노출 1,000회 미만이거나 전환 10건 미만인 소재는 "판단 보류"로 따로 둔다.
- 잘 된 소재와 안 된 소재가 무엇이 다른지(첫 장면, 문구 방식, 형식, 타깃) 적는다.

## 2. 가설 수립
한 번에 하나만 바꾸는 가설로 쓴다.

> "<타깃>에게 <무엇>을 <이렇게> 바꾸면 <지표>가 오를 것이다. 근거: <1의 관찰 또는 02의 고객 표현>."

가설을 3개 이내로 고르고, 기대 효과가 크고 만들기 쉬운 순으로 줄 세운다.

## 3. 테스트 설계

| 항목 | 내용 |
|---|---|
| 바꾸는 것 | 한 가지 (나머지는 그대로) |
| A / B | 기존 / 새 소재 |
| 판단 지표 | 하나 (예: 전환당 비용) |
| 예산·기간 | 소재당 일 예산, 최소 며칠 |
| 끝내는 기준 | 언제 승자를 정하고, 언제 무승부로 접는지 |

새 소재가 필요하면 04·05·06 스킬로 만든다.

## 광고 계정을 건드릴 때
캠페인 생성, 예산 변경, 켜기·끄기는 돈이 나가는 일이다. 바꿀 내용과 하루 최대 지출을 보여 주고 건마다 확인받은 뒤 실행한다. 확인 없이 예산을 올리지 않는다. 실행 뒤에는 바뀐 상태를 다시 읽어 확인한다.
