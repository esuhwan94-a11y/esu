# 05 디자인

입력: `brief.md`, `03-콘텐츠기획.md`, `04-카피대본.md` · 출력: `ads/<광고주>/05-디자인/`

## 1. 콘셉트 설정
`05-디자인/콘셉트.md`에 한 번 정해 두고 모든 게시물에 똑같이 쓴다.
- 색 3~4개(brief의 브랜드 색 우선), 글꼴 느낌, 사진 분위기, 여백
- 표지·본문·마지막 장의 배치 규칙
- 광고주가 준 로고·제품 사진의 위치

## 2. 이미지 제작
- 크기: 인스타 피드 4:5(1080×1350), 스토리·릴스 표지 9:16(1080×1920), 정사각 1:1.
- 제품 사진은 광고주가 준 실제 사진을 쓴다. 생성 이미지는 배경·분위기 컷에 쓰고, 제품 모양이나 효능을 실제와 다르게 그리지 않는다.
- 생성은 Higgsfield 연결의 이미지 도구로 한다. 먼저 예상 크레딧(estimate_image_cost)과 만들 장수를 보여 주고 승인받는다.
- 실존 인물, 남의 캐릭터·로고가 들어가는 이미지는 만들지 않는다.

## 3. 카드 완성
- 04의 문구를 장마다 얹는다. 문구는 HTML로 조판해 이미지로 뽑거나, 이미지 도구에 글자까지 맡겼다면 한글이 깨지지 않았는지 한 장씩 확인한다.
- 휴대폰 크기로 봤을 때 표지 문구가 읽히는지 본다.
- 파일 이름: `<날짜>-<주제>-<장번호>.png`
- `05-디자인/목록.md`에 게시물별 파일과 쓴 문구 버전을 적는다.

## 끝나고 알릴 것
만든 장수, 쓴 크레딧, 광고주 확인이 필요한 장(제품이 보이는 컷).
